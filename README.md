# ToDoManager

Простой менеджер задач на языке Go для управления списком дел.

## Описание

ToDoManager — это консольное приложение для:
- добавления новых задач;
- удаления задач;
- отметки задач как выполненных;
- фильтрации задач;
- сохранения списка задач между запусками.

## Возможности

- Создание задач с названием и описанием
- Установка приоритета задач
- Отметка задачи как выполненной/невыполненной
- Просмотр всех задач или только активных
- Сохранение и загрузка данных в JSON/CSV файл

## Требования

- Go 1.20 или выше
- Git
- Операционная система: Windows, Linux или macOS

## Установка

1. Создайте копию репозитория 
```bash
git clone https://github.com/David-Puge/ToDo-Manager
cd ToDoManager
```

2. Соберите исполняемый файл (Готовый исполняемый файл уже есть в проекте)
Скомпилируйте проект, чтобы получить готовый инструмент командной строки:
```bash
go build -o todo cmd/todo/main.go
```


## === Команды ===
- add -name "Название задачи" -desc "Описание задачи" - добавляет задачу в список
- del -id 1 - удаляет задачу по ID
- list -filter all/done/pending (all по умолчанию) - выводит список задач в зависимости от фильтра
- complite -task 1 - меняет статус задачи на противоположный (выполнено/не выполнено) по её ID
- export -fail "Путь файла" -format json/csv - экспортирует список задач в указанный файл в формате JSON или CSV
- load -fail "Путь файла" -format json/csv - загружает список задач из указанного файла в формате JSON или CSV
