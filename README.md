# ToDoManager

Простой менеджер задач на языке Go для управления списком дел.

## Описание

ToDoManager — это консольное приложение для:
- добавления новых задач;
- удаления задач;
- отметки задач как выполненных;
- фильтрации задач;
- сохранения списка задач между запусками.

## Возможности

- Создание задач с названием и описанием
- Установка приоритета задач
- Отметка задачи как выполненной/невыполненной
- Просмотр всех задач или только активных
- Сохранение и загрузка данных в JSON/CSV файл

## Требования

- Go 1.20 или выше
- Git
- Операционная система: Windows, Linux или macOS

## Установка

1. Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd ToDoManager
```

2. Установите зависимости:

```bash
go mod tidy
```

3. Запустите приложение:

```bash
go run .
```

## Использование

После запуска приложения вы увидите меню с доступными командами, например:

```text
1. Добавить задачу
2. Показать все задачи
3. Отметить как выполненную
4. Удалить задачу
5. Поиск задач
6. Выход
```

Пример работы с задачами:

```text
> Добавить задачу
Введите название: Купить продукты
Введите описание: Молоко, яйца, хлеб
Выберите приоритет: 2
Задача добавлена
```
